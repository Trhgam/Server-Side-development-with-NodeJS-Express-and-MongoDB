#position:
+ static : ko dịch chuyển được,là  các thể mặc định
+ relative : hồn canh theo xác 
div{
position : relative;
top : 2rem;
left 2 rem; } chạy xuống 2rem so với div chứa nó ,tự canh chỉnh với nó ở static
+ absolute :  canh chỉnh theo cha ,cha phải khác static,hoặc muốn nó canh chỉnh theo gì thì biến cái đó thành relative
div{
position :  absolute;
top 50% left 50%
transform : translate(-50%,-50%)
}
lưu ý combo ra giữa
muốn ra giữa thì phải so thê, với chính nó
c1 : dùng relative(cha) + absolute(div muốn đánh ra giữa) 
c2 : dùng flex-box 
có thể dùng z-index cho nó ra tầng sau hay trước z-index : 999/-1
+fixed : ôm theo màn hình  vĩnh viễn 
+sticky : dòng chữ đầu trang,to đùng đùng ,dùng làm menu đầu trang 
.div{
	position :sticky;
	top 1rem;
}

pseudo tag : span div
pseudo class : :hover|:active |:unvisited | :focus
pseudo element : ::before | ::after ko sờ được nhưng vẫn hiện,tạo hiệu ứng

@inline-block:thẻ mà có khối chỉ bao gồm content mà thôi tức là nó ko cố gắng chiếm hết dòng mà chỉ chiếm đủ block của content nó có mà thôi.inline block là 1 hộp ôm sát nên ko có sang trái phải được
block sang trái phải được vì nó là 1 cái hộp rỗng lớn ,ko ôm 
có skill có thể cho phép inline-block ra giữa đó là lồng trong thẻ div
inline (ko phải inline block hay block nha, ko có màu cam,ko có bọc viền)
tag formating: display : inline chỉ có nội dung content thôi,chỉ có màu xanh và ko có hộp block
ví dụ inline span,em
vid dụ inline-block img input button select text
inline-block là loại thẻ "có khối chỉ bao gồm content mà thôi", "không cố gắng chiếm hết dòng" và "có thể lồng thẻ div để ra giữa".
